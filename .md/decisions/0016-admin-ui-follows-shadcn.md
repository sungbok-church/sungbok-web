# ADR 0016: 관리자 화면은 shadcn admin 기준을 따르고 색만 이 사이트 것으로 바꾼다

**상태**: 채택 — 아래 세 곳은 ADR 0018 로 달라졌다: ① «동작 줄이기» 는 부품에 `motion-reduce` 를 덧붙이지 않고 `globals.css` 가 끈다 ② 메뉴 버튼의 `outline` 변형은 빼지 않았다(원본 그대로) ③ 공용 부품(`Button` · `Input`)도 원본 크기가 됐다
**날짜**: 2026-11-18
**관련 문서**: [domains/admin.md](../domains/admin.md) · [design/design-system.md](../design/design-system.md) · [DESIGN.md](../../DESIGN.md) · [specs/2026-11-17-admin-design.md](../specs/2026-11-17-admin-design.md)

## 배경

디자인 시스템([design-system.md](../design/design-system.md))은 관리자 화면을 «같은 색과 폰트, 더 촘촘하게, 연출 모션 없음» 으로 정했고, 디자인 바([DESIGN.md](../../DESIGN.md))의 규칙 — 한글 최소 13px, 1024 미만 폭에서 터치 영역 44px, 폭 같은 레이아웃 속성은 애니메이션하지 않는다 — 을 관리자에도 그대로 적용했다.

관리자 틀을 shadcn 의 sidebar 부품으로 짜면서 이 규칙에 맞추느라 원본을 고쳤다: 좁은 화면 기준을 `md`(768) → `lg`(1024)로, 접고 펼치는 폭 전환을 제거, 글자를 `text-label` · `text-caption` 으로, 메뉴 항목 높이를 44px 로. 사용자가 이를 보고 원본대로 가라고 정했다 — «관리자에 연출 모션을 왜 안 넣어, 글자 크기와 터치 영역, 좁은 화면 기준 모두 shadcn 원본으로 가야지».

## 결정

**관리자(`/admin`)는 shadcn admin 의 부품과 배치를 원본 그대로 쓰고, 색만 이 사이트의 팔레트로 바꾼다.**

- **원본을 따르는 것**: 배치, 글자 크기(`text-sm` · `text-xs` 등), 요소 크기와 터치 영역, 좁은 화면 기준(`md`), 모션(접고 펼치는 폭 전환 등).
- **이 사이트 것으로 바꾸는 것**: 색 — shadcn 의 의미 토큰(`--sidebar-*` 등)이 B1 팔레트를 가리킨다([color-palette.md](../design/color-palette.md)). 폰트(Pretendard)와 문구(한글, 사실 진술)도 이 사이트 것이다.
- **관리자에 적용하지 않는 디자인 바**: 한글 최소 13px, 1024 미만 터치 44px, 레이아웃 속성 애니메이션 금지, «관리자는 연출 모션 없음».
- **관리자에도 그대로 적용하는 것**: 색 하드코딩 금지(토큰만), 포커스 표시, 대비, `prefers-reduced-motion`(원본의 전환에 `motion-reduce:transition-none` 을 덧붙인다 — «동작 줄이기» 를 켠 사람에게만 달라진다), 문구 톤.
- **원본에서 빼는 것**: 린트가 막는 부분만 — 난수를 쓰는 `SidebarMenuSkeleton`(`react-hooks/purity`), 임의 그림자를 쓰는 메뉴 버튼의 `outline` 변형(`design:lint`). 둘 다 쓰지 않는 부분이다.

공개 사이트의 디자인 바는 바뀌지 않는다.

## 대안 비교

| 안 | 결과 |
|---|---|
| 관리자도 공개 사이트와 같은 바를 지킨다(원본을 고쳐 쓴다) | ✗ 부품을 들일 때마다 고쳐야 하고, 고친 만큼 shadcn admin 의 모양·동작과 달라진다. 원본을 갱신하기도 어렵다 |
| 공개 템플릿 저장소를 통째로 들인다 | ✗ 자기 테마와 의존성(인증·상태 관리)이 따라온다(관리자 설계 4절) |
| **shadcn 원본 그대로 + 색만 교체** | ✓ 채택(사용자 결정) |

## 영향

- 관리자 화면의 작은 글자(12px)와 작은 터치 영역(메뉴 항목 32px 등)은 위반이 아니다. `pnpm design:audit` 을 관리자 화면에 돌리면 터치·글씨 항목이 걸릴 수 있다 — 관리자 화면은 가로 넘침만 본다.
- 이미 이 사이트 기준으로 맞춰 둔 공용 부품(`Button` 44px · `Input` 44px · 16px 등)은 공개 화면도 쓰므로 그대로 둔다. 관리자 화면에서 shadcn 크기가 필요하면 그 화면이 크기를 지정한다.
- 휴대폰에서 관리자를 쓸 때 누르기가 공개 사이트보다 좁다. 불편이 확인되면 이 결정을 다시 본다.
