# ADR 0026: 홈페이지 메뉴 — 코드는 «어떤 페이지», DB 는 «덮어쓸 값»

**상태**: 채택
**날짜**: 2026-11-25
**관련**: [ADR 0004](0004-subpage-routing.md)(바꾸는 결정), [설계 6.5](../specs/2026-11-17-admin-design.md), [패키지 D 계획](../specs/2026-11-25-admin-pd-sitemenu-plan.md)

## 배경

ADR 0004 는 `siteNav.ts` 를 메뉴 · 라우트 · 상위 주소 넘김의 단일 소스로 정했다. 관리자에서 교회 사람이 홈페이지 메뉴의 이름 · 순서 · 사용 여부를 바꾸려면 그 값이 DB 에 있어야 한다. 페이지 파일은 코드에만 있으므로 «어떤 페이지가 있는가» 까지 DB 로 옮길 수는 없다.

## 결정

- **코드 `siteNav` = 어떤 페이지가 있는가**(주소 · 기본 이름 · 기본 순서). 페이지 파일과 짝은 `siteNav.test` 가 잠근다(전과 같다).
- **DB `menus(area = 'SITE')` = 덮어쓸 값**(이름 · 순서 · 사용 여부). 초기 행은 `reference.sql` 에 `siteNav` 와 같게 두고 `siteMenuSeed.test` 가 잠근다. 주소로 짝을 짓는다.
- 둘을 합치는 것은 순수 함수 하나(`mergeSiteNav`). 공개 쪽은 캐시한 합친 메뉴(`loadSiteNav`, 태그 `site-menus`)를 `(site)` 레이아웃이 한 번 읽어 `SiteNavProvider` 로 독 · 휴대폰 메뉴 · 섹션 머리에 넘긴다. DB 를 못 읽으면 코드 메뉴로 그린다.
- **끈 메뉴는 없는 페이지(404)**: 메뉴 페이지 폴더마다 얇은 `layout.tsx`(`siteMenuRoute`)가 막고 브라우저 제목(«이름 | 성복교회»)도 만든다. 그 아래 글 페이지도 함께 막힌다. 하위가 모두 꺼진 상위도 메뉴에서 빠진다.
- **상위 주소(`/about`)는 접속 때 넘긴다**: ADR 0004 의 빌드 때 307 넘김(`next.config` redirects) 대신 `<섹션>/route.ts`(`sectionLandingRoute` — 경로 처리기)가 켜진 첫 하위로 307 로 넘긴다(페이지에서 넘기면 미리 그린 틀 뒤 흘려보내는 부분이라 200 + 브라우저 넘김이 되고, 미리 그린 넘김은 메뉴가 바뀌어도 다시 그려지지 않았다 — 로컬 실측). 옛 주소 넘김(`/map` 등)은 `next.config` 에 그대로.
- **잠긴 메뉴**: 홈이 고정 링크로 가리키는 곳(찾아오시는 길 · 교회소식 › 주일광고 · 예배 › 주일예배 · 다음세대 8부서와 그 상위)은 끌 수 없다 — DB 제약(`not (is_locked and not is_active)`)이 막는다.

## 대안 비교

| 대안 | 탈락 이유 |
|---|---|
| 메뉴 전체(페이지 목록 포함)를 DB 로 | DB 에 페이지를 더해도 페이지 파일이 없으면 404 — 화면에서 «추가» 를 할 수 없는데 데이터만 열어 두는 셈 |
| 끈 메뉴 막기를 `proxy` 에서 | 공개 요청마다 DB 를 한 번 더 읽는다(캐시 밖). 메뉴 데이터 캐시와 갱신 길이 둘이 된다 |
| 페이지마다 막기 한 줄 | 글 페이지(주보 한 호 등)까지 빠짐없이 넣어야 한다 — 폴더 레이아웃 하나가 그 아래를 모두 덮는다 |
| 상위 주소 넘김을 빌드 때 그대로 | 첫 하위를 끄면 넘긴 곳이 404 가 된다 |

## 결과 / 영향

- 메뉴를 저장하면(`updateMenu` · `reorderMenus`) 관리자 화면과 함께 `site-menus` 태그를 갱신해 공개 메뉴 · 제목 · 404 가 바로 바뀐다.
- 새 페이지를 더할 때: `siteNav` · 페이지 파일 · 그 폴더의 `siteMenuRoute` 레이아웃 · `reference.sql` 의 홈페이지 메뉴 줄을 함께(테스트가 하나라도 빠지면 잡는다). 운영 DB 에는 `db:sync` 가 만든 초기 행 변경 파일로.
- 부서 이름(부서 페이지 사진의 대체 텍스트 기본값)은 아직 코드(`departmentInfo`) — 페이지 제목 · 메뉴는 메뉴 이름을 따른다.
