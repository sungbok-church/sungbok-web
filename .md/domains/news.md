# 교회소식 (`/news/*`)

| 메뉴 | 주소 | 화면 |
|---|---|---|
| 주일광고 | `/news/announcements` · `/news/announcements/영상id` | **영상**. 예배 설교와 같은 화면(목록 + 한 편) |
| 주보 | `/news/bulletin` · `/news/bulletin/날짜` | B안 «바로 읽기» |
| 성복의 뜰 | `/news/garden` · `/news/garden/영상id` | **영상**. 예배 설교와 같은 화면 |
| 교회앨범 | `/news/album` · `/news/album/id` | C안 «목록 + 미리보기» |

별도 공지사항 메뉴는 두지 않는다(2026-10-08 회의). 결정 배경: [ADR 0014](../decisions/0014-content-repository-and-video-id-link.md).

## 주일광고 · 성복의 뜰 — 영상

- 글 게시판이 아니라 **영상 화면**이다. 화면 부품은 예배 설교의 것을 그대로 쓴다([worship-video.md](worship-video.md) «영상 페이지»). 다른 것은 문구와 묶는 방식뿐이다(`config/videoPageProfile`).
- 영상은 유튜브 재생목록이 아니라 **등록한 게시글**에서 온다 — 게시글 하나 = 유튜브 영상 하나(`NewsVideo`).
- **영상 id 가 빈 글은 목록에 싣지 않는다.** 영상이 비었다는 이유로 글만 있는 화면으로 바꾸지 않는다.
- 글에 적혀 있던 내용(주일광고의 광고 본문, 성복의 뜰의 행사 안내)은 영상 아래 **설명란**에 보인다 — 3줄로 접혀 있고 «더보기» 로 편다(예배 설교의 유튜브 설명란과 같은 자리). 한글 문서에서 붙여 넣은 표는 한 행을 한 줄로, 칸은 « · » 로 이었다.
- 주일광고: 칩은 연도, 날짜로도 찾는다(«10.25»). 성복의 뜰: 칩은 분류(부흥집회·교회소식).
- 주일광고는 **제목이 곧 날짜**(«11월 15일 주일 광고»)라 날짜를 한 번 더 적지 않는다 — 목록 맨 위 큰 카드에는 날짜 줄이 없고, 목록 줄과 옆 목록에는 제목에 없는 연도(«2026년»)만 적는다(`videoPageProfile` 의 `dateInTitle`).
- 한 편 화면의 옆 목록과 이전·다음은 묶음 없이 전체 날짜순이다(회차가 없는 영상이라).
- 날짜: 주일광고는 광고한 주일, 성복의 뜰은 제목의 행사 날짜. 행사 날짜를 모르면 유튜브 업로드 날짜를 쓰고 화면에 «업로드» 를 붙인다.
- 썸네일 주소는 등록할 때 실제로 있는 것을 확인해 적는다 — 큰 표지(`maxresdefault`)가 없는 영상이 있다.

## 주보 — B안 «바로 읽기»

- 들어오면 **최신 주보가 펼쳐져** 있다. 머리(«11월 8일 주보» · «2026년 · 최신 주보») + 「크게 보기」 하나.
- 다른 호 고르기: **PC·태블릿**은 왼쪽 「다른 주보 보기」 — 연도별 접이식 목록(보고 있는 연도는 늘 펼침) 안에 월별 묶음. **휴대폰**은 「다른 주보 보기」 한 줄 → 바텀시트(연도 탭 + 월별 목록). 셀렉트박스는 쓰지 않는다. 연도 목록은 자료에서 자동으로 나온다.
- 그림 한 장(1200×854)이 **펼친 두 면**이다. 「한 면 / 양면」과 (한 면일 때) 「왼쪽 / 오른쪽」을 고정된 선택 버튼(44px)으로 한 줄에 둔다. 휴대폰 기본은 한 면·오른쪽(첫 장의 오른쪽이 표지), 태블릿부터는 양면. 고르기 전의 모양은 CSS 가 가른다(스크립트로 폭을 읽으면 휴대폰에서 한 번 깜빡인다).
- 「크게 보기」는 하나다 — 하단 «전체 화면» 같은 중복 버튼을 두지 않는다. 종이 그림을 눌러도 같은 뷰어가 열린다.
- 다른 호를 골라도 **페이지를 옮기지 않는다.** 주소만 `/news/bulletin/날짜` 로 바꾸고(`syncAddress` — `history.replaceState`) **펼칠 호를 주소에서 읽는다**(`idFromPath` + `usePathname`). 고른 호를 화면 안의 상태로 들고 있으면 안 된다 — Next 는 `replaceState` 때 주소만 바꾸고 페이지는 그대로 두어서, 다른 메뉴에 갔다가 «뒤로» 오면 주소는 그 호인데 화면은 최신 호가 된다. 탭 제목도 같이 맞춘다. 새로고침·공유하면 그 호가 열리고, 없는 날짜는 404. 교회앨범도 같은 방식이다.

## 교회앨범 — C안 «목록 + 미리보기»

- 항목을 고르면 옆(휴대폰·태블릿은 아래)에 화보가 보이고 「크게 보기」 하나로 뷰어를 연다. «자세히 보기», 별도 상세 화면, 하단 반복 목록은 없다 — 고른 항목은 주소(`/news/album/id`)에만 맞춘다.
- 화보는 사진과 글을 편집한 세로 포스터다 — **전체 비율 그대로** 보인다(자르지 않는다). 목록의 작은 그림도 같다.
- 휴대폰은 소개 문구 없이 바로 분류 칩과 목록이다. 검색은 아이콘으로 접어 두고, 접으면 검색어도 비운다. PC 는 검색칸이 늘 보인다.
- 분류 칩은 자료의 분류에서 자동으로 나온다.

## «크게 보기» 뷰어

주보와 앨범이 같이 쓴다(`features/ImageViewer`). 장 넘김(←/→ 키) · 확대 100~300%(50% 단위, «맞춤») · 주보일 때만 한 면/양면·왼쪽/오른쪽. Esc · 바깥 · 닫기 버튼으로 닫고, 닫히면 **연 버튼으로 포커스가 돌아간다**(Radix 는 `Dialog.Trigger` 로 열었을 때만 돌려놓아서 뷰어가 직접 적어 둔다). 휴대폰은 화면 전체.

## 구조

| 파일 | 맡은 일 |
|---|---|
| `api/news.types.ts` | `NewsVideo` · `BulletinIssue` · `Album` |
| `api/newsRepository.ts` | 공개 자료 읽기(영상·주보·앨범). 임시저장과 보여 줄 것이 없는 글은 여기서 거른다. **화면은 이 저장소로만 읽는다** |
| `api/bulletinList.ts` | 연도·월 묶기, 표시 문구, «최신» 판정(순수) |
| `api/albumList.ts` | 분류·검색·표시 문구(순수) |
| `api/syncAddress.ts` | 페이지 이동 없이 주소 맞추기(`syncAddress`)와 주소에서 고른 항목 읽기(`idFromPath`) |
| `data/*Seed.ts` | 기존 사이트 게시판을 전부 옮긴 시드(2026-11-16): 주일광고 87편 · 성복의 뜰 30편 · 주보 90호(2025-03-02 ~ 2026-11-15) · 앨범 4건 |
| `components/widgets/BulletinPage` · `AlbumPage` | 주보·앨범 화면 |
| `components/features/ImageViewer` · `SpreadImage` | 뷰어, 양면 그림. 장 넘김·확대·선택 버튼은 공용 `shared/components/features/ViewerControls` |

그림은 `public/files/bulletin/<날짜>-<n>.webp`, `public/files/album/<id>-<n>.webp`.

## 관리자 연동

자료실과 같은 방식이다([resources.md](resources.md) «관리자 등록과 예배 시트지 연결») — 지금은 시드, 관리자·DB 가 생기면 `newsRepository` 의 `load` 만 바꾼다. 주일광고·성복의 뜰은 제목·분류·날짜와 **유튜브 영상 id** 를 등록하고, 주보는 주일 날짜와 그림(4장), 앨범은 제목·분류·그림을 올린다.

## 미결·다음

- **기존 사이트에서 싣지 못한 글 둘**: 2025-11-09 주일광고(붙어 있는 영상이 11월 16일 광고와 같은 영상 — 유튜브 제목도 «11월16일») · 성복의 뜰 «2026 가을특별부흥집회 11.13 이요셉 목사»(유튜브에서 볼 수 없는 영상). 교회에서 영상을 바로잡으면 등록한다.
- **옮긴 뒤에 기존 사이트에 올라오는 글**(매주 주보·주일광고·시트지)은 자동으로 넘어오지 않는다 — 관리자가 생기기 전까지는 다시 옮겨야 한다.
- 성복의 뜰의 분류는 제목으로 정했다(«부흥집회»·«REVIVAL» → 부흥집회, 그 밖 → 교회소식). 날짜는 제목·본문에 연월일이 있으면 그 날짜, 없으면 유튜브 업로드 날짜(9편, 화면에 «업로드» 표시).

- 주일광고를 매주 올리는 방식(영상 id 직접 등록 대 재생목록 자동) — 지금은 등록 방식이다. 유튜브에 주일광고 재생목록이 따로 있으면 예배처럼 자동으로 바꿀 수 있다(`worshipPages` 에 재생목록 한 줄).
- 주보가 해마다 50호씩 쌓인다 — 목록은 연도별로 접혀 있어 괜찮지만, 페이지에 전 호의 그림 주소가 실린다. 수백 호가 되면 연도별로 나눠 받게 고친다.
- 앨범의 분류(교회행사·다음세대)는 시안에서 정한 값이다 — 교회에 확인이 필요하다.
